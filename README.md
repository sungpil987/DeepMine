# DEEPMINE 2.0 · 더 깊은 세계

세로형 Android 채굴 게임. 네트워크·광고·결제 없이 광석을 캐고, 판매하고, 광산을 키웁니다. Canvas로 직접 그린 동굴·광물·곡괭이·드론과 WebView 셸을 사용합니다.

## 2.0 콘텐츠

- **광물 50종 / 5개 광구**: 고요한 동굴, 수정 숲, 빙하 균열, 잿불 심층, 별의 심연. 각 10종씩, 서로 다른 배경·색상·획득 가치·내구도.
- 최초 10종 광물 ID 유지. 별빛석 다음으로 세계수 결정·영원의 서리·용의 심장·태초의 별 등 추가.
- 광석 25개마다 해당 광구의 보스 광맥 출현. 내구도 4배, 광물 5개와 연구 결정 보상. 보스 격파 전 광구 이동 불가.
- **오버드라이브**: 10초 피해 3배, 60초 재사용. 꾹 눌러 연속 채굴.
- **연구소 3종**: 피해, 풍부한 광맥 확률, 자동 작업 효율. 보스·에픽 광물·탐사·보상으로 결정을 획득.
- **제작 공방**: 석탄·구리로 폭탄 3개 제작. 철·은으로 영구 자동 채굴 드론 제작(최대 10대).
- **광물별 판매 잠금**: 잠근 광물은 판매 대상에서 제외. 제작 재료로는 사용 가능.
- **무인 탐사**: 200 G, 5분 대기. 출발 광구의 네 번째 광물 3개와 연구 결정 획득. 앱 종료 후에도 진행.
- **업적 9종**, 7일 순환 출석 보상, 반복 의뢰.
- 첫 에픽 이상 발견·보스 격파 연출, 광구별 배경 효과, 업그레이드 단계별 곡괭이 외형.
- 백업 코드 생성·복사·붙여넣기 복원. 복원은 2단계 확인 후 진행.

## 기존 데이터

기존 `deepmine-v1` 키를 유지하고 v1→v2 상태를 마이그레이션합니다. 골드, 최초 10종의 광물·발견 기록, 강화 레벨, 채굴 수, 의뢰, 폭탄, 현재 광석과 남은 내구도를 유지합니다. 이전 원본은 별도 `deepmine-before-v2` 키에도 보관합니다. 복원 전 기록은 `deepmine-before-import` 키에 보관합니다.

**중요: 저장 형식 호환성과 APK 서명은 별개입니다.** 1.0 빌드는 임시 debug 키를 매 실행 새로 생성했으므로 이전 APK와 2.0 APK의 서명을 직접 비교해 서로 다름을 확인했습니다. 따라서 기존 1.0 위에 덮어설치할 수 없습니다. 기존 앱을 삭제하면 기기의 저장 기록도 삭제될 수 있습니다. 2.0부터 개발 키를 Actions 캐시로 재사용하지만, 캐시 유실 후까지 동일 서명을 보장하지는 못합니다. 장기 배포에는 소유자가 관리하는 고정 release 키와 GitHub Secrets 구성이 필요합니다. 키 자체는 저장소에 커밋하지 않습니다.

## 게임 규칙

- 일반 광석은 지역별 가중 추첨. 장비의 행운은 RARE 이상의 가중치를 올립니다. 도감에서 지역별 현재 확률 확인.
- 80번째 광석은 에픽 이상 보장. 에픽 이상 등장 시 카운터 초기화.
- 풍부한 광맥은 기본 5%(연구로 최대 25%), 내구도 2배·획득량 3배.
- 연속 5타마다 피해 +10%, 최대 +40%. 치명타 피해 3배.
- 폭탄은 일반 광석 최대 내구도의 60%, 보스는 20% 피해.
- 도감에 신규 광물 등록 시 전체 판매가 +2%. 자동 채굴 레벨당 타격 1회/초.
- 오프라인 수익은 자동 타격 1회/초당 0.25 G/초, 최대 4시간. 무인 탐사 보상은 직접 수령.
- 광구 전환 시 진행 중인 일반 광석은 새로 추첨. 골드·가방은 유지.
- 출석은 기기의 로컬 날짜 기준. 온라인 계정·서버 동기화는 없음.

## APK

GitHub Actions → `Android APK` → 성공 실행의 `DeepMine-APK` → ZIP 해제.

- **기존 1.0 사용자:** `DeepMine-2.0-separate.apk`를 설치하세요. 패키지명 `com.peter.deepmine.v2`, 표시명 `딥마인 2.0`. 1.0 앱과 기록을 그대로 남기고 별도로 설치됩니다. 2.0은 새 기록으로 시작하며 1.0 진행도는 자동 이전되지 않습니다.
- `DeepMine-2.0-update.apk`: 원래 패키지명 유지. 원래 패키지로 설치된 호환 서명의 2.0이 있거나, 해당 패키지가 아직 설치되지 않은 경우에 사용하세요. 기존 1.0에는 덮어설치되지 않습니다.
- 두 APK는 각각의 앱 저장 공간을 사용합니다. 2.0 설정의 백업 코드를 이용하면 두 앱 간 기록을 수동 이전할 수 있습니다. 1.0에는 백업 내보내기 UI가 없습니다.

JDK 17 / Gradle 8.9 / Android SDK 35 / minSdk 26. Android 패키지명 `com.peter.deepmine`, 버전 `2.0.0`(코드 2).

```sh
node tests/engine.test.cjs
node tests/ui.test.cjs # Playwright + Chromium 필요
# 로컬 APK 빌드
 gradle assembleDebug --no-daemon
```

브라우저 빠른 실행: `app/src/main/assets/index.html` 열기.

## 구조와 검증

- `engine.js`: 추첨·경제·이동·보스·제작·연구·업적·일일 보상·저장 마이그레이션.
- `game.js`: 메뉴·클릭·길게 누르기·타이머·음향·백업.
- `scene.js`: 광구 아트·결정 형태·파편·곡괭이·드론 렌더링.
- 엔진 16개 시나리오 그룹: v1 복원, 판매 잠금, 제작 차감, 지역 해금, 보장 추첨, 보스·폭탄, 연구, 스킬, 오프라인 중복 방지, 출석·탐사·업적, 10만 회 시드 추첨 등.
- 모바일 브라우저 통합 테스트: 320/390/430px, 채굴·장비·출석·50개 도감·5개 지역·제작·탐사·업적·보스 연출·백업·복원·새로고침.
- Actions에서 로직·브라우저 테스트를 통과한 뒤 APK 컴파일. 실제 Android 기기의 설치·플레이 검증은 별도 필요.
